Программный код

Эмпирическая часть написана на Python и лежит в папке code/ репозитория github.com/rniwd/algorithm-analysis-textbook. Для запуска нужен Python 3 и matplotlib:

python3 -m pip install matplotlib
cd code
python3 run_all.py            # все скрипты со счётчиками
python3 verify_answers.py     # проверка всех числовых ответов задач и квизов
ФайлЧто проверяет
m1_max_element.pyMaxElement: $C(n) = n - 1$
m1_unique_elements.pyUniqueElements: оба худших входа $\frac{n(n-1)}{2}$, лучший $1$
m1_matrix.pyматрицы: $M(n) = A(n) = n^3$
m1_binary.pyBinary: $\lfloor\log_2 n\rfloor + 1$; цикл $i \leftarrow 2i$
m1_sequential_search.pyсредний случай $\frac{p(n+1)}{2} + n(1-p)$
m1_selection_sort.py, m1_upper_sum.py, m1_dependent_loops.pyсвои примеры модуля 1 и циклы с зависимой границей
m2_factorial.py, m2_hanoi.py, m2_binrec.py, m2_fibonacci.pyразборы модуля 2
m2_rec_max.py, m2_fast_pow.py, m2_rec_sum.pyсвои примеры модуля 2, лимит рекурсии в Python
tasks/m1_e1_triple_loop.py, tasks/m2_e1_split.pyрешения эмпирических задач
verify_answers.pyвсе числовые ответы задач и квизов сайта

Графики из этих скриптов показаны в разделах эмпирической проверки модуля 1 и модуля 2.

Инструменты

  • Формулы набраны с помощью KaTeX, подсветка кода — highlight.js. Визуализации написаны на чистом JavaScript и SVG без библиотек.
  • Графики эмпирической части построены в matplotlib.
  • Сайт статический, работает на GitHub Pages и при открытии index.html с диска; прогресс квизов хранится только в вашем браузере.

Использование ИИ

При подготовке учебника использовался ассистент Claude Code: черновики текста, псевдокода, задач, визуализаций и скриптов. Все определения и формулы сверены с книгой Левитина. Числовые ответы проверены программой verify_answers.py, решения проверены участниками группы вручную. Подробности — в отчёте группы.
