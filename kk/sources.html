Бағдарламалық код

Эмпирикалық бөлім Python тілінде жазылған және github.com/rniwd/algorithm-analysis-textbook репозиторийінің code/ қалтасында орналасқан. Іске қосу үшін Python 3 және matplotlib қажет:

python3 -m pip install matplotlib
cd code
python3 run_all.py            # санауыштары бар барлық скрипттер
python3 verify_answers.py     # есептер мен тесттердің барлық сандық жауаптарын тексеру
ФайлНені тексереді
m1_max_element.pyMaxElement: $C(n) = n - 1$
m1_unique_elements.pyUniqueElements: ең нашар жағдайдың екі кірісі де $\frac{n(n-1)}{2}$, ең жақсы жағдай $1$
m1_matrix.pyматрицалар: $M(n) = A(n) = n^3$
m1_binary.pyBinary: $\lfloor\log_2 n\rfloor + 1$; $i \leftarrow 2i$ циклы
m1_sequential_search.pyорташа жағдай $\frac{p(n+1)}{2} + n(1-p)$
m1_selection_sort.py, m1_upper_sum.py, m1_dependent_loops.py1-модульдің өз мысалдары және тәуелді шекарасы бар циклдар
m2_factorial.py, m2_hanoi.py, m2_binrec.py, m2_fibonacci.py2-модульдің талданған мысалдары
m2_rec_max.py, m2_fast_pow.py, m2_rec_sum.py2-модульдің өз мысалдары, Python-дағы рекурсия шегі
tasks/m1_e1_triple_loop.py, tasks/m2_e1_split.pyэмпирикалық есептердің шешімдері
verify_answers.pyсайттағы есептер мен тесттердің барлық сандық жауаптары

Осы скрипттер салған графиктер Модуль 1 және Модуль 2 эмпирикалық тексеру бөлімдерінде көрсетілген.

Құралдар

  • Формулалар KaTeX көмегімен терілген, кодты бояп көрсету — highlight.js. Визуализациялар кітапханаларсыз таза JavaScript пен SVG-де жазылған.
  • Эмпирикалық бөлімнің графиктері matplotlib-те салынған.
  • Сайт статикалық, GitHub Pages-те және index.html файлын дисктен ашқанда жұмыс істейді; тест прогресі тек сіздің браузеріңізде сақталады.

ЖИ-ді пайдалану

Оқулықты дайындау кезінде Claude Code ассистенті пайдаланылды: мәтіннің, псевдокодтың, есептердің, визуализациялар мен скрипттердің жобалары. Барлық анықтамалар мен формулалар Левитин кітабымен салыстырылып тексерілді. Сандық жауаптар verify_answers.py бағдарламасымен тексерілді, шешімдерді топ мүшелері қолмен тексерді. Толығырақ — топтың есебінде.
