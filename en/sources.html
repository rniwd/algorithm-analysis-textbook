Program code

The empirical part is written in Python and is located in the code/ folder of the repository github.com/rniwd/algorithm-analysis-textbook. To run it you need Python 3 and matplotlib:

python3 -m pip install matplotlib
cd code
python3 run_all.py            # all scripts with counters
python3 verify_answers.py     # checks all numerical answers to problems and quizzes
FileWhat it checks
m1_max_element.pyMaxElement: $C(n) = n - 1$
m1_unique_elements.pyUniqueElements: both worst-case inputs $\frac{n(n-1)}{2}$, best case $1$
m1_matrix.pymatrices: $M(n) = A(n) = n^3$
m1_binary.pyBinary: $\lfloor\log_2 n\rfloor + 1$; the loop $i \leftarrow 2i$
m1_sequential_search.pyaverage case $\frac{p(n+1)}{2} + n(1-p)$
m1_selection_sort.py, m1_upper_sum.py, m1_dependent_loops.pyown examples of Module 1 and loops with a dependent bound
m2_factorial.py, m2_hanoi.py, m2_binrec.py, m2_fibonacci.pyworked examples of Module 2
m2_rec_max.py, m2_fast_pow.py, m2_rec_sum.pyown examples of Module 2, Python recursion limit
tasks/m1_e1_triple_loop.py, tasks/m2_e1_split.pysolutions to the empirical problems
verify_answers.pyall numerical answers to the site's problems and quizzes

The charts produced by these scripts are shown in the empirical check sections of Module 1 and Module 2.

Tools

  • Formulas are typeset with KaTeX, code highlighting uses highlight.js. The visualizations are written in plain JavaScript and SVG without libraries.
  • The charts of the empirical part were made with matplotlib.
  • The site is static; it runs on GitHub Pages and when index.html is opened from disk. Quiz progress is stored only in your browser.

Use of AI

The Claude Code assistant was used in preparing the textbook: drafts of the text, pseudocode, problems, visualizations and scripts. All definitions and formulas were checked against Levitin's book. Numerical answers were verified by the verify_answers.py program, and the solutions were checked by hand by the group members. Details are in the group report.
