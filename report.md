Собственный статический HTML-сайт (HTML, CSS, JavaScript без фреймворков), опубликован на GitHub Pages и открывается по ссылке без установки программ. Формулы набраны в KaTeX, визуализации написаны на SVG и JavaScript без библиотек. Сайт адаптирован для телефона, есть тёмная тема.

## 3. Проверка корректности

- `code/run_all.py`: 17 скриптов со счётчиками базовой операции. Каждый сравнивает счётчик с формулой (таблица «n | счётчик | формула | совпадает») и строит график. Все 17 скриптов: совпадает.
- `code/verify_answers.py` автоматически проверяет все числовые ответы задач и квизов (66 проверок) и структуру банка заданий. Все проверки пройдены.
- Автоматическая проверка сайта в браузере (Playwright, ширина 1280 и 390 px). Проверено: ошибок в консоли нет, все формулы отрисованы, ссылки и якоря работают, нет горизонтальной прокрутки на телефоне, квизы считают баллы и сохраняют прогресс, подсказки, ответы и решения раскрываются, Ханойская башня для n = 1…8 делает ровно 2ⁿ − 1 ходов.
- Независимая сверка каждой формулы и решения с текстом Левитина. Найденные замечания исправлены (_перечислить при необходимости_).
