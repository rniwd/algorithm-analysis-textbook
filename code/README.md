# Код к электронному учебнику: эмпирический анализ алгоритмов

Скрипты на Python к темам Левитина «Алгоритмы: введение в разработку и анализ»
(§2.3–2.5): анализ нерекурсивных и рекурсивных алгоритмов. Каждый скрипт
реализует алгоритм строго по псевдокоду, явно считает **базовую операцию**,
сравнивает счётчик с выведенной формулой, печатает таблицу
`n | счётчик | формула | совпадает` и сохраняет график.

## Установка

Нужен Python 3.10+ и matplotlib (остальное — стандартная библиотека):

```bash
python3 -m pip install matplotlib
```

## Запуск

```bash
cd code
python3 m1_max_element.py          # один скрипт
python3 tasks/m1_e1_triple_loop.py # решение задачи
python3 run_all.py                 # все скрипты + сводка OK/FAIL
```

Скрипты работают и из корня проекта: `python3 code/run_all.py`.
Код возврата 1 означает, что хотя бы одна строка не совпала с формулой.

## verify_answers.py

Проверяет **все числовые ответы сайта**: квизов и задач.

```bash
cd code
python3 verify_answers.py
```

Как это устроено:

1. В файлах `data/quizzes.js`, `data/tasks-m1.js`, `data/tasks-m2.js` у каждого
   вопроса или задачи с числовым ответом есть строка `checks: [...]` в формате JSON.
   В ней указано, какой алгоритм запустить, какую формулу ответа проверить
   и на каких n.
2. Скрипт читает эти строки, запускает собственную реализацию алгоритма
   со счётчиком базовой операции (или прямо вычисляет сумму или рекуррентность)
   и сравнивает результат с формулой ответа.
3. Отдельно проверяются числа, приведённые в тексте разборов (список `CLAIMS`):
   7 сравнений у Binary(100), 14 умножений для a^1000 и т. п.
4. Проверяется структура банка заданий: в каждом вопросе ровно один верный вариант,
   объяснение у каждого варианта, у каждой задачи есть подсказка, ответ и решение.
   Печатается количество вопросов и задач по типам.

Код возврата 0 означает, что все проверки пройдены. Последняя строка вывода:
`ИТОГ: все проверки пройдены (66 числовых проверок, структура в порядке)`.

Скрипт не заменяет ручную проверку решений: он проверяет числа и формулы,
но не ход рассуждений.
